# 5.1 初識函式原理分析

函式把具名操作、輸入與結果封裝成可重用單位。先看一個可以直接編譯執行的例子：

## 函式的一般格式

先記住下列「讀函式用骨架」。角括號中的中文字是說明用佔位文字，不是要原樣輸入 C++：

```cpp
回傳型別 函式名稱(參數型別 參數名稱, ...) {
    // 函式本文：要執行的敘述
    return 回傳值; // 只有非 void 函式需要回傳相容的值
}
```

例如 `int add(int left, int right)` 可拆成：

- `int`：回傳型別；呼叫端會收到一個整數結果。
- `add`：函式名稱。
- `(int left, int right)`：參數清單；此函式需要兩個整數，分別用 `left` 和 `right` 作為函式內名稱。
- `{ ... }`：函式本文，描述呼叫時執行的程式。
- `return left + right;`：計算並把結果交還呼叫端。`;` 結束這個敘述。

若函式不回傳結果，回傳型別寫 `void`，本文可用 `return;` 提早結束，也可執行到結尾自然返回。參數清單為空時可寫 `()`。稍後會依序學習如何用參考參數修改呼叫端資料、如何回傳結構和錯誤；一般函式介面的形狀先用上述骨架辨認即可。

```cpp
#include <iostream>

int clamp_to_range(int value, int low, int high) {
    if (value < low) {
        return low;
    }
    if (value > high) {
        return high;
    }
    return value;
}

int main() {
    std::cout << clamp_to_range(12, 0, 10) << '\n'; // 10
    std::cout << clamp_to_range(-3, 0, 10) << '\n'; // 0
    std::cout << clamp_to_range(5, 0, 10) << '\n';  // 5
}
```

讀程式時先找函式的三部分：回傳型別 `int`、名稱 `clamp_to_range`、參數清單。呼叫端給入三個引數；函式依序判斷值是否低於下界或高於上界，最後 `return` 結果。三次呼叫的輸出分別為 10、0、5。

本函式假設呼叫端提供 `low <= high`。正式介面要驗證這個前置條件，或明確記錄違反時的錯誤策略；錯誤回報方式依模組要求選擇，本節不先引入例外語法。

### 宣告和定義

**宣告**告訴呼叫端函式名稱、參數和回傳型別；**定義**提供函式本體。呼叫前必須看得到宣告：

```cpp
int clamp_to_range(int value, int low, int high); // 宣告

int clamp_to_range(int value, int low, int high) { // 定義
    // 函式本體
}
```

在同一檔案中，宣告通常緊鄰定義；多檔案中將宣告放入標頭的方式會在[5.10 多檔案程式](section_10.md)示範。參數與區域變數在函式呼叫期間有效，詳細作用域見[5.3](section_3.md)。

閱讀完整函式時，先由左至右找回傳型別、函式名稱和參數清單，再進入大括號讀本文；呼叫時提供的引數需和參數順序及型別相容。這個閱讀次序也適用於成員函式，差別是成員函式還隸屬於某個類別。

函式通常應表達一項清楚的操作。是否拆分以可理解、可測試和穩定的抽象邊界為準，而不是硬性依行數切割。
