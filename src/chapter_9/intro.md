# 第九章：C++ 的併發編程

本章先補上訊息伺服器會用到的 `std::map`、函式指標與可呼叫物件，再進入執行緒、互斥鎖、非同步結果，最後循序完成一個程序內訊息伺服器模型。

多執行緒最難的不是建立執行緒，而是定義共享資料的所有權、同步方式、停止條件及錯誤傳遞。所有共享狀態都必須有明確規則；「程式跑得動」不代表沒有資料競爭。

## 學習目標

- 使用關聯容器建立可查找的訊息處理器表。
- 分辨函式指標、成員函式指標、`std::function`、`std::bind` 與 Lambda 的適用場景。
- 以 `std::thread` / `std::jthread` 啟動並安全結束工作。
- 使用 `std::mutex` 保護共享狀態，理解鎖的範圍與死結風險。
- 使用 `std::async` / `std::future` 取得非同步計算結果。
- 逐步建立具佇列、停止策略與可重複測試的訊息處理服務。

範例以 C++20 為主，並在使用 `std::jthread`、`std::stop_token` 等 C++20 特性時明確標示。標準執行緒程式仍需依編譯器與平台使用正確的執行緒連結設定。
