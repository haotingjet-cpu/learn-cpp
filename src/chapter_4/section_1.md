# 4.1 C++ `for` 迴圈語法分析

`for` 適合知道初始化方式、繼續條件和每輪更新方式的重複工作。一般格式是：

```cpp
for (初始化; 繼續條件; 每輪更新) {
    // 每一輪要執行的敘述
}
```

三個欄位之間用分號隔開；條件在每輪開始前檢查，為 `false` 就離開。初始化通常建立計數變數且只執行一次，更新通常在本文執行完後發生。先用數字從 1 累加到 4，手動追蹤三個欄位：

```cpp
#include <iostream>

int main() {
    for (int i{1}; i <= 4; ++i) {
        std::cout << i << '\n';
    }
}
```

執行順序是：`i` 初始化為 1、檢查 `i <= 4`、執行輸出、執行 `++i`，再回到條件檢查。輸出 4 後更新為 5，條件為假，迴圈結束。`init` 只跑一次；`condition` 每輪開始前跑；`update` 在本體結束後跑。

## 常見邊界錯誤

若改成 `i < 4`，輸出會是 1、2、3，而不包含 4；因此比較符號要配合「最後一個值是否包含」的需求。計數容器時通常使用 `i < count`，因為有效索引從 0 到 `count - 1`。若誤寫 `i <= count`，最後一輪會多處理一個不存在的元素。vector 和容器索引會在[4.6 陣列與 vector](section_6.md)具體說明。

## 多個更新動作與巢狀迴圈

`for` 更新欄位可增加計數或調整索引；但複雜到難以一眼看懂時，將更新移到本體並改用 `while` 可能更清楚。巢狀迴圈中內層每完成一輪，外層才更新一次；可用乘法表例子預測總執行次數。

逐元素走訪容器可用 range-for；目前尚未介紹容器，請先看[4.6](section_6.md)，再回頭比較索引迴圈和 range-for。
