# 3.3 算術運算、逐位非與或

邏輯運算處理真假值；位元運算逐位處理整數。名稱和部分符號很像，但用途不同。以下先用 4 位元的小例子手算 `OR`、`AND` 和 `NOT`：

| 輸入 A | 輸入 B | `A & B` | `A | B` |
|---|---|---|---|
| `0101` | `0011` | `0001` | `0111` |

在 C++ 中，`&&`／`||` 是邏輯運算；`&`／`|` 是位元運算。`!` 將真假翻轉；`~` 將型別中所有位元翻轉。先前的算術章節說明了整數型別和值域，詳見[第二章算術運算](../chapter_2/section_3.md)。

```cpp
#include <cstdint>
#include <iostream>

int main() {
    std::uint32_t flags{0b0101};
    flags |= 0b0010; // 設定 bit 1：0101 | 0010 = 0111

    const bool has_bit_2 = (flags & 0b0100) != 0;
    flags &= ~std::uint32_t{0b0001}; // 清除 bit 0

    std::cout << has_bit_2 << '\n'; // 1，bit 2 原本為 1
    std::cout << flags << '\n';     // 6，即二進位 0110
}
```

這類 `flags` 可以把一個整數的不同位元當成多個獨立開關。`flags |= mask` 設定遮罩中為 1 的位元；`flags &= ~mask` 清除遮罩中為 1 的位元；`flags & mask` 可檢查指定位元是否有開啟。程式列印布林值時，預設會輸出 `1` 或 `0`。

真實程式應把 `0b0100` 這類值命名，例如 `constexpr std::uint32_t read_flag{0b0100};`，並選擇可容納所有旗標的無號型別。遮罩的建立和位移量有型別範圍限制，不要不加檢查地寫 `1 << n`。

負數的位移和平台位元表示細節容易產生陷阱；解析協定或序列化資料時，先用無號整數並明確定義每一位的意義。列舉型別如何替旗標命名會在[3.11 列舉型別](section_11.md)延伸。
